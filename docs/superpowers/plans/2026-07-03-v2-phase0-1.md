# V2 Overhaul — Phases 0–1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the v2 integration branch with working CI/review rails, then acquire fresh Sefaria source data and produce the divergence audit and manual-edit replay set.

**Architecture:** Rails changes land on `main` first (canonical), then `v2` is cut from `main` so PRs into `v2` inherit working workflows. Phase 1 adds three small Bun/TypeScript tools under `scripts/pipeline/` that produce committed evidence artifacts (`data/source/`, `docs/v2/`). Checkpoint outcomes are recorded in the spec **via PRs to `main`** (the spec is canonical on `main`; weekly `main→v2` merges carry it forward — `v2` only merges back at cutover).

**Tech Stack:** Bun + TypeScript (scripts), `bun test`, GitHub Actions, CodeRabbit, `gh` CLI, `jq`, mongodb-database-tools (`bsondump`, for the Sefaria dump).

**User decisions (already made)** — from `docs/specs/2026-07-03-v2-overhaul-design.md` (V1–V9) and conversation:
- Rebuild data from the true Sefaria source; `data/raw/` is untrusted intermediate (V1).
- `v2` = long-lived integration branch; feature branches PR into it with full review (V2).
- Subtractive start: delete v1 app files, keep rails + `data/` (V3, V5).
- New code at final paths, no `v2/` subdirectory (V4).
- Checkpoints are blocking gates; standing decisions re-asked there (V7).
- Data-edit freeze on `main` once Phase 1 starts (V8); weekly `main→v2` merge (V9).
- CI + CodeRabbit must be **demonstrated** working on a test PR into `v2` before other PRs land (spec task 0.2).

**Plan-level decisions (made here, flag at CP-0 if wrong):**
- `data/admin/` is **kept** in the deletion PR — CI tests (`bun qa:test`) cover `server.test.ts`, and it remains the editor for v1 data until Phase 3 replaces it.
- Deploy configs (`wrangler.jsonc`, `.assetsignore`, `.cfignore`, `_headers` excepted) are kept; `_headers` is deleted with the app it serves. Cloudflare branch previews of `v2` will 404 until Phase 4 — expected.
- `ci-scorecard.yml` stays main-only (OpenSSF Scorecard only scores the default branch).
- Fetched source artifacts are committed under `data/source/` (consistent with existing data-in-git practice); their PRs use the `bulk-data-ok` label.

- [ ] **Step 2: Implement `scripts/pipeline/lib/compare-entries.ts`:**

```ts
export interface SourceEntry {
	rid: string;
	headword: string;
	alt_headwords?: string[];
	content?: { senses?: unknown[] };
	[key: string]: unknown;
}

export interface ChangedEntry {
	rid: string;
	fields: string[];
}

export interface CompareResult {
	onlyInFresh: string[];
	onlyInRaw: string[];
	changed: ChangedEntry[];
}

const stable = (v: unknown): string => JSON.stringify(v ?? null);

const COMPARED_FIELDS = ['headword', 'alt_headwords'] as const;

export function compareEntryMaps(
	fresh: Map<string, SourceEntry>,
	raw: Map<string, SourceEntry>,
): CompareResult {
	const onlyInFresh = [...fresh.keys()].filter((rid) => !raw.has(rid)).sort();
	const onlyInRaw = [...raw.keys()].filter((rid) => !fresh.has(rid)).sort();
	const changed: ChangedEntry[] = [];
	for (const [rid, f] of fresh) {
		const r = raw.get(rid);
		if (!r) continue;
		const fields: string[] = [];
		for (const field of COMPARED_FIELDS) {
			if (stable(f[field]) !== stable(r[field])) fields.push(field);
		}
		const fSenses = f.content?.senses?.length ?? 0;
		const rSenses = r.content?.senses?.length ?? 0;
		if (fSenses !== rSenses) fields.push('senseCount');
		// Compare the untracked remainder independently — a named-field
		// change must not mask additional drift elsewhere in the entry.
		const restF: Record<string, unknown> = { ...f };
		const restR: Record<string, unknown> = { ...r };
		for (const field of COMPARED_FIELDS) {
			delete restF[field];
			delete restR[field];
		}
		if (stable(restF) !== stable(restR)) fields.push('other');
		if (fields.length > 0) changed.push({ rid, fields });
	}
	changed.sort((a, b) => a.rid.localeCompare(b.rid));
	return { onlyInFresh, onlyInRaw, changed };
}
```

```ts
export interface EditRecord {
	id: string;
	op: 'add' | 'remove' | 'modify';
	before?: string;
	after?: string;
}

function idOf(line: string): string | null {
	try {
		const doc = JSON.parse(line) as { id?: unknown };
		return typeof doc.id === 'string' ? doc.id : null;
	} catch {
		return null;
	}
}

export function parseJsonlDiff(diffText: string): EditRecord[] {
	const removed = new Map<string, string>();
	const added = new Map<string, string>();
	for (const line of diffText.split('\n')) {
		if (line.startsWith('---') || line.startsWith('+++')) continue;
		const isMinus = line.startsWith('-');
		const isPlus = line.startsWith('+');
		if (!isMinus && !isPlus) continue;
		const body = line.slice(1);
		const id = idOf(body);
		if (!id) continue;
		(isMinus ? removed : added).set(id, body);
	}
	const records: EditRecord[] = [];
	for (const [id, before] of removed) {
		const after = added.get(id);
		if (after !== undefined) {
			records.push({ id, op: 'modify', before, after });
			added.delete(id);
		} else {
			records.push({ id, op: 'remove', before });
		}
	}
	for (const [id, after] of added) records.push({ id, op: 'add', after });
	records.sort((a, b) => a.id.localeCompare(b.id));
	return records;
}
```
