# URL Words Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the pointed-headword URL names with URL words (letters, maqaf, geresh, gershayim) numbered in rid order, and remove the superscript disambiguator and `formerNames` from entry data and code.

**Architecture:** Two pure functions in `admin/lib/url-path.ts` compute every entry's path from the entries alone; nothing is stored. `admin/entry/names.ts` and its uniqueness check go; the only address check left is "no URL word is empty". The disambiguator leaves the schema, the parser, gate 2, the headword-issues report and the Sefaria appendix, and the entry files are regenerated by the import at `schemaVersion` 3.

**Tech Stack:** Bun 1.4.3, TypeScript, TypeBox schema, Biome 2.5.15, `bun test`.

**Spec:** [`2026-11-13-url-words-design.md`](2026-11-13-url-words-design.md); ruling `11-13 url words` in [`../decisions.md`](../decisions.md).

## Review Focus

1. **NFD or mark-order input** to `toUrlWord`: the same headword with marks in another order must give the same word. Test in Task 1.
2. **Spaced headwords** (C00517 `גזא דפטי`, A02002 `כְּפַר א׳ אָמוּס`): `_` between words, geresh kept, no `__` or edge `_`. Test in Task 1.
3. **The three patch-added superscripts** (A00055, C00300, G00675) have none in `sefariaHeadword`: the headword-issues findings must not change because of them. Checked by the report diff in Task 3.
4. **`duplicateForms` losing its disambiguator key** could turn a line whose primary repeats as an alternate, told apart only by `²`, into a new review row. Expect `headword-duplicate-form=4` after the re-import (it is 4 before). Checked in Task 3.
5. **A group renumbering** after A00055 joins A00056's word `אבוב`: A00055 is `/אבוב` and A00056 `/אבוב-2`. Test in Task 2 against the committed tree.
