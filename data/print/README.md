# Print

Scans of the two printed volumes that `data/page-index/` is pinned to.

The only thing here today is `hocr/` — the raw OCR of both scans, kept
byte-exact so the page index can always be re-checked against what it
was built from. See [`hocr/README.md`](hocr/README.md) for the scan
provenance, the source items, and how to verify the bytes.

## Rights

Public domain, with everything else under `data/`. See
[`hocr/README.md`](hocr/README.md) for who scanned it and who to
credit.
