# Print

The OCR of the two scans reviewed patches cite as evidence (ruling
`11-01 print images`).

The only thing here today is `hocr/` — the raw OCR of both scans, kept
byte-exact: the page index was built from it, and the import's
evidence gate reads it. How the scans' leaves map to printed pages is
`admin/pipeline/patch/scan.ts`. See [`hocr/README.md`](hocr/README.md) for the scan
provenance, the source items, and how to verify the bytes.
