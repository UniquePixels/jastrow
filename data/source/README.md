# Source — the Sefaria export

The Jastrow lexicon as exported from Sefaria's MongoDB
(`lexicon_entry`, `parent_lexicon: "Jastrow Dictionary"`), snapshot
2026-07-04, 32,512 entries. Fetched by `bun data:fetch`
(`admin/pipeline/fetch.ts`) from Sefaria's public dump.

## Rights and attribution

Marcus Jastrow's *Dictionary of the Targumim…* (London: Luzac, 1903)
is out of copyright. Sefaria declares the same 1903 edition public
domain: as observed 2026-09-22, `GET /api/texts/versions/Jastrow`
returns `"license": "Public Domain"` with
`"digitizedBySefaria": true`. That endpoint describes the `Jastrow`
*text* index, not the `lexicon_entry` collection this project reads.

The `lexicon_entry` collection carries no licence field of its own —
see `lexicons.json`, which has `attribution`, `source` and
`version_title` and no rights key. Same 1903 digitization, a
different collection.

**Credit is owed to Sefaria for the digitization**, whether or not a
licence compels it.

## What is Sefaria's, and what is this pipeline's

Three files are tracked in git — a fresh clone holds exactly these,
plus this README:

| File | Whose |
|---|---|
| `jastrow-dictionary.jsonl` | Sefaria's export, unmodified |
| `lexicons.json` | Sefaria's lexicon metadata, unmodified |
| `manifest.json` | this pipeline's record of the fetch, written by `data:fetch` (`fetch.ts`) |

The two Sefaria files above are the snapshot every patch record pins
itself to (`admin/pipeline/patch/records/snapshot.lock`). Nothing else
here is hashed, because nothing else is source.

Two further names are sometimes seen here. Both are gitignored —
local run output, never source, never committed:

| File | What it is |
|---|---|
| `migration-report.json` | this pipeline's account of the last import, written by `data:import` (`migrate.ts`) |
| `body-census-report.json` | a census of the grammar vocabulary; still read by `body/grammar.test.ts` when present, but the tool that wrote it (`body:census`) was archived to `refs/tags/archive/v2-research-2026-09` and cannot be regenerated by anything in the live tree |

Four more sat here until 2026-09-22 and were none of the above —
orphaned output of investigations already archived, plus the v1
admin-tool edit history. They moved to
`docs/archive/source-reports-2026-09-22/`, which lists them: this
directory now holds only what an import reads and what one run
writes.
